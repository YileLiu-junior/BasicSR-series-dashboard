## 📊 为什么会有这个东西

不是"我想做个看板"，是三个具体的受不了：

| 受不了的瞬间 | 原来是什么样 |
|---|---|
| **翻知识库** | 在 VSCode 里看 markdown，渲染得像一份没排好版的说明书，读三行就想合上 |
| **追 idea 出处** | agent 干活太勤，实验跑多了，回头就忘了这个 idea 是哪次讨论、哪篇论文之后冒出来的 |
| **决定下一步** | 思路一多就失忆 —— "等等，我下一步本来要干嘛来着？" |

于是干脆做一个页面，把这三件事钉在一起：**状态看得见、出处追得到、下一步忘不掉。**

没打算做产品，也没打算给别人用。就是给自己修个顺手的工具箱。

## 这个工作台里有什么

数据只有一个来源：`app/data/data.json`。所有视图都是它的不同切面，刷新浏览器即生效，不用重启服务。

| 视图 | 干什么 |
|---|---|
| **总览** | 当前前沿条 · 知识库更新 feed · 待做清单（NEXT + 按 idea 分组）· 三臂监控大屏（ETA 滚动倒计时）· Agent/Skill 使用指南 · 基线锚点 |
| **实验监控** | 三条线（L1/L2/L3）的进度、ETA、loss 曲线；点行进黑底详情，双 tab「运行详情 / 实验配置 YAML」 |
| **Idea 溯源** | 每条 idea 的来源、状态与挂载实验；进行中的卡片带流光描边 |
| **消融台账** | 消融项列表 + 筛选（筛选计数自动统计），负结果一眼可见 |
| **知识库阅读器** | 7 分类面包屑 + 左侧多层目录 + 黑底 markdown 正文 + 右侧常驻助理 |
| **助理** | 右下角悬浮球，点开是对话框；接任意 OpenAI 兼容 API 做实验问答。Key 只存浏览器 localStorage，不上传 |

数据怎么更新进来的：

```
710 服务器 tmp_trio/lvl{1,2,3}.log
        │  scp / 手动拷贝
        ▼
python tools/parse_trio_log.py --log lvl1.log --arm L1 --data data/data.json
        │  解析最新 INFO 行（iter / epoch / lr / eta / l_pix / l_freq）+ 采样 loss 序列
        ▼
app/data/data.json  ←── 也可以直接用任何文本编辑器手改
        │  浏览器 fetch
        ▼
        页面渲染（刷新即生效）
```

## 🧪 它不只能伺候 BasicSR

虽然是为 BasicLLIE 实验搭的，但它本质上不是"BasicLLIE 专用工具"，而是**一个外壳 + 一份数据契约**。换个课题也能直接接管：

**不用改代码的部分** —— 视图骨架（总览/监控/台账/溯源/知识库）、快照式数据流、零依赖静态栈、深链路由（`#view=wiki` / `#arm=L1`）、Playwright 回归门、悬浮助理。

**换课题只需要改这四处**：

| 改哪 | 换成什么 |
|---|---|
| `app/data/data.json` | 你的实验字段（契约见 [`app/SPEC.md`](app/SPEC.md) §3） |
| `app/assets/wiki-data.js` | 你自己的知识库结构（补 `md` 字段即可接全文，渲染器不用动） |
| `app/tools/parse_trio_log.py` | 匹配你的训练框架日志输出的正则 |
| `app/assets/style.css` 的 `:root` | 换一套配色变量 |

所以它其实是个**个人深度学习科研的通用外壳**：只要你的工作是"一堆跑很久的实验 + 一堆散落的笔记 + 一个总在忘记的 todo"，这套东西就能套上去。任何有训练日志、有配置、有知识库要维护的深度学习课题 —— BasicSR 系列、检测、分割、diffusion —— 都可以照着改。

**一个前提**：它是按**单人 / 本地 / 快照**设计的。多人协作、实时数据库、权限管理这类需求 [`app/SPEC.md`](app/SPEC.md) §6 明确划在 v1 之外，那样得换架构。

## 快速开始

需要 Node.js（跑本地服务）和 Python 3（跑日志解析，可选）。

```powershell
cd app
node tools/server.mjs
```

浏览器打开 http://localhost:8765 。必须走 http —— 数据由 `fetch` 加载，`file://` 双击会被浏览器拦。

跑回归校验（19 项 Playwright 断言，复用系统 Chrome）：

```powershell
node tools/verify.mjs
```

更细的启动方式、数据更新流程、校验清单，见 [`app/README.md`](app/README.md) 和 [`app/SPEC.md`](app/SPEC.md)。
